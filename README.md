# BEAM 数智虚拟实验室（C6 抛弃式原型）

## 复制到比赛笔记本前的要求

假设目标电脑为 Windows 10/11 64位，只需要：

1. 安装 **Python 3.11 64位**，安装时勾选 **Add Python to PATH**；
2. 保证比赛当天电脑能访问互联网；
3. 完整复制整个 `virtual-lab-prototype` 文件夹，不要漏掉 `tools` 和 `vendor`；
4. 在目标电脑上提前运行一次 `.\start-public.cmd`，用手机关闭 Wi-Fi、只开流量完成实测。

不需要系统安装 Cloudflare，不需要另行运行 `pip install`，也不需要管理员权限。`cloudflared.exe`、二维码生成库及其纯 Python PNG 依赖均已包含在项目文件夹中。

如果目标电脑已安装 Conda，但普通 PowerShell 中的 `python` 命令不可用，可以直接指定 Conda Python：

```powershell
.\start-public.cmd -PythonExe "D:\Anaconda3\python.exe"
```

脚本也会自动检查当前 Conda 环境，以及用户目录下常见的 `anaconda3`、`miniconda3` 安装位置，并忽略会跳转微软商店的 `WindowsApps\python.exe` 别名。

## 这个原型只回答一个问题

同一个课堂入口，能否让教师分阶段发布，让学生完整经历：**先行判断 → 受力数验 → 变形释理 → 迁移校核**？

它不回答视觉精修、长期数据存储、智林平台集成、正式部署和大班稳定性问题。所有状态只在内存中，关闭服务即清空。

## 一条命令启动

在本目录运行：

```powershell
python server.py
```

启动后终端会显示带随机口令的教师端网址与带本轮课堂密钥的学生端网址。教师和学生都必须使用终端或教师页给出的完整网址，不要手工删掉其中的 `token=` 或 `key=`。默认只监听 `127.0.0.1`，端口为 `8765`；如需改端口：

```powershell
python server.py --port 9000
```

## 让学生只开手机流量即可扫码

项目内已有通过官方 SHA-256 校验的 `tools/cloudflared.exe`。在本目录运行：

```powershell
.\start-public.cmd
```

命令会同时启动本地实验室与临时公网隧道，并显示两个地址：教师端只在本机打开，学生端形如 `https://随机名称.trycloudflare.com/student?key=本轮随机密钥`。本机教师页中的二维码会自动使用完整公网学生地址。学生只需手机能上网即可扫码，判断、实验进度和迁移结果会通过隧道返回教师端；教师口令不经过公网隧道。

公网启动成功后会自动打开教师驾驶舱，课堂中不需要再回到 PowerShell。驾驶舱在同一页面提供：

- 固定的“上一步／发布下一步”控制条；
- 等待、判断、受力、协调、迁移、完成六阶段快捷定位；
- 二维码、课堂统计和投票比例；
- 与学生当前阶段同步的只读预览；
- “放大学生预览／返回驾驶舱”投屏切换。

教师可以在预览中演示投票、滑块和校核按钮，但这些操作不会写入课堂数据；真实学生手机提交仍会正常计入。教师无需另开学生端页面。

试讲或比赛结束后运行：

```powershell
.\stop-public.cmd
```

关闭服务会清空本轮内存数据，并立即使临时公网学生地址失效。启动脚本会记录本轮 Python 服务和 Quick Tunnel 的进程号及启动时间；关闭脚本只停止与该记录精确匹配的两个进程，不扫描或批量关闭电脑上的其他 Python 任务。

Quick Tunnel 每次重新启动都会更换地址，只适合开发和试讲。固定网址需要 Cloudflare 账号、一个接入 Cloudflare 的域名，以及 Named Tunnel。

若页面一直显示“连接中”，不要继续使用旧网址。先运行 `stop-public.cmd`，再重新运行 `start-public.cmd`，并使用新输出的完整网址。当前启动脚本会自动检查浏览器脚本的类型；入口密钥失效或配置接口失败时，页面会明确显示“连接失败”，而不是永久停在“连接中”。

## 网络安全边界

- 公网模式的 Python 服务仅监听本机回环地址 `127.0.0.1`，不直接向校园网或公网开放端口；公网流量只经 Cloudflare 的 HTTPS 出站隧道进入。
- 教师操作使用每次启动新生成的随机口令；学生入口使用另一枚独立的本轮随机密钥。学生密钥不能执行发布阶段或重置操作。
- 学生只提交匿名浏览器随机 ID 和课堂操作，不提交姓名、学号、密码或文件；状态只在内存保存，停止服务即清空。
- 服务限制 JSON 请求体为 16 KiB、每轮最多 32 台设备、每个来源每分钟最多 120 次写操作，并限制允许的操作类型与设备 ID 格式。
- 已启用 CSP、禁止跨站页面嵌入、禁止 MIME 猜测、无来源信息外发、HTTPS HSTS 和不缓存等浏览器安全响应头；仅允许同源教师驾驶舱嵌入学生预览，静态文件路径经过根目录约束。
- 学生完整网址属于本轮共享课堂凭证，不要提前公开发布；教师网址中含 `token=`，任何时候都不要发送给学生。比赛结束后立即运行 `stop-public.cmd`。

以上措施显著降低越权、路径穿越、脚本注入和资源滥用风险，但任何临时公网服务都不能承诺“绝对不会被攻击”。Quick Tunnel 也不提供正式生产环境的可用性保证；本原型的安全前提是短时开启、不收集敏感信息、仅用于现场课堂。

## 走通顺序

1. 教师发布“先行研判”，学生提交一次立场判断。
2. 教师发布“受力数验”，学生拖动 `X₁`，观察平衡残差始终为零。
3. 教师发布“协调释理”，学生打开变形并让两个销孔对正，锁定 `X₁=3ql/8`。
4. 教师发布“迁移校核”，学生运行梁单元 FEM 与静定基本体系解析路线的三点对照。
5. 教师端实时看到投票、受力观察、真解锁定与迁移运行数量。

## 原型边界

- 计算采用无量纲参数 `q=l=EI=1`。
- 学生设备以浏览器随机 ID 匿名计数，不记录姓名。
- 二维参数计算和联动画面是确定性数字工具，不宣称为 AI。
- 二维梁单元路线与解析位移函数路线相互独立，用于验证 C5 的“全场迁移”叙事。
- 二维码图片由本机生成，不依赖外部二维码网站；学生页面和课堂状态同步由本机完成。
- 教师发布和重置操作受随机口令保护；教师网址只在本机打开，不要把带 `token=` 的教师网址发给学生。
